# Актуальные экраны CoPlaying

Из пакета current-app от 29 октября 2026 в портфолио включены только:

- `01-catalog.jpg` — каталог игр; на главной и в начале кейса.
- `19-create-slot.jpg` — форма выбора даты и времени.
- `20-create-call-contact.jpg` — выбор способа созвона и контакта.

Каталог скопирован целиком. У двух широких снимков удалены только пустые боковые поля рабочего стола: сохранена полная центральная колонка приложения шириной 480 px, без обрезки интерфейса и без генеративной перерисовки. Оригиналы в current-app не изменены; подготовленные формы сохранены в PNG без дополнительной потери качества. Любой экран можно увеличить. Дашборды владельца, списки игроков, профили и закрытые контакты в публичные ресурсы не включены. Числа на экранах — состояние интерфейса в момент съёмки, не доказательство роста.

Репозиторий `kotlyarenkoru-eng/CoPlaying` использован через GitHub MCP только на чтение: метаданные, src/styles.css и публичный знак. При выборе шрифта использованы локальные Onest 400/500/600/700 и их OFL-лицензия. Код и данные рабочего CoPlaying не изменялись.
