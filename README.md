# Портфолио Владислава Котляренко

Статический сайт productdeveloper.ru на GitHub Pages. Фреймворков и зависимостей для сборки нет.

## Где менять

- `index.html` — исходная вёрстка и тексты. **Ссылки на медиа — в начале файла**, в `PORTFOLIO_ASSETS`, рядом с комментарием на русском.
- `responsive.css` — правила шрифта, адаптивности, отступов и отображения медиа.
- `enhancements.js` — маршруты, мобильный бургер, параллакс объектов и просмотр изображений.
- `assets/media/` — облегчённые изображения проектов; оригиналы в корне сохранены.
- `assets/coplaying/` — актуальные экраны CoPlaying. Их происхождение — `docs/MEDIA-SOURCES.md`.
- `assets/fonts/` — Onest для кириллицы и латиницы, лицензия OFL рядом.
- `assets/kotlyarenko-pm-coplaying.docx` — резюме для скачивания.

Добавьте медиа в репозиторий и замените путь в `PORTFOLIO_ASSETS`. Для внешнего файла используйте HTTPS. `coplayingScreen` задаёт каталог на главной, `coplayingCatalog/Create/Call` — изображения внутри кейса. Пропорции сохраняются, изображения можно увеличить.

Видео «Обо мне» воспроизводится без звука и имеет паузу. Движение учитывает настройку уменьшения анимации. Escape закрывает просмотр изображения и возвращает фокус.

## Сборка и проверка

`npm run build` или `node scripts/build.mjs` проверяет локальные ссылки и структуру документа, затем собирает готовый сайт в `dist/`. Установка пакетов не требуется. `npm run check` дополнительно проверяет синтаксис поведения сайта.

Для предпросмотра запустите статический HTTP-сервер из корня и откройте `dist/`. Проверяйте мобильное меню, обычные переходы между кейсами, возврат к месту на главной, увеличение медиа, видео и скачивание резюме.

Стандарт дизайна — `docs/DESIGN-RULES.md`, результаты проверки — `docs/VALIDATION.md`. Код, данные и репозиторий рабочего CoPlaying не изменяются.
