# Портфолио Владислава Котляренко

Статический сайт productdeveloper.ru, GitHub Pages. Сборка и установка зависимостей не нужны.

## Где менять

- `index.html` — исходная вёрстка и тексты. **Все ссылки на медиа собраны в начале файла** в `PORTFOLIO_ASSETS`, рядом с комментарием на русском.
- `responsive.css` — дополнения к адаптивности и интерфейсу внутренних кейсов.
- `enhancements.js` — маршруты, главы, мобильное меню, интерактивность объектов и просмотр изображений.
- `assets/media/` — облегчённые копии исходных медиа; оригиналы в корне сохранены.
- `assets/kotlyarenko-pm-coplaying.docx` — резюме для скачивания.

Добавьте изображение или видео в репозиторий и замените соответствующее значение в `PORTFOLIO_ASSETS`. `coplayingScreen` может оставаться пустым: тогда показывается графическая обложка. После добавления скриншота вставьте его путь в этот ключ. Для локального файла используйте путь с точным регистром, для внешнего — HTTPS.

Видео «Обо мне» сохраняет автоматическое воспроизведение без звука, имеет паузу и уважает настройку уменьшения движения. Остальные видео имеют стандартное управление. Изображения внутри кейсов можно увеличить; Escape закрывает просмотр и возвращает фокус.

## Проверка

Запустите любой статический HTTP-сервер из корня репозитория. Проверьте главную, все кейсы, прямую ссылку вида `#/coplaying/coplaying-chapter-1`, возврат к месту на главной, меню на телефоне, клавиатуру, медиа и скачивание резюме.

История решений об оформлении — `DESIGN.md`; границы авторских текстов и факты — `docs/CONTENT-SOURCES.md`.
